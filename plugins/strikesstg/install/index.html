StrikesSTG is built for Paper. Match the download to your exact server line.

Setup in three steps

  1. Download the StrikesSTG jar for your Paper version from CurseForge (or compile from GitHub).
  2. Install by placing the jar in plugins/ and restarting the server once.
  3. Configure banned words and ban-thresholds in config.yml, then restart.

First run creates

  • config.yml
  • strikes.yml

Example config keys: banned-words list and ban-thresholds with strike counts and durations.
