Features

A tiny embedded web server inside the plugin — tune bind address, port, and colors in plugins/LogsSTG/config.yml.

Live log stream

Watch INFO, WARN, and ERROR lines as they happen. Late joiners receive a configurable history buffer.

Command line

Run console commands from the page. Slash prefix is optional. Command history with up/down arrows.

Startup message

The plugin logs the exact URL on boot, e.g. Live logs at http://127.0.0.1:8765/.

Configurable bind

host and port in config. Default loopback-only for safety.

Theme colors

Set page background and text colors per level in config — #RGB or #RRGGBB.

Hot reload

/logsstg restart reloads the web UI without restarting the server (OP / logsstg.restart).

History buffer

history controls how many past lines new viewers receive (50–5000).

Multi-version builds

Separate jars for Paper 1.21.11, 26.1, 26.1.2, 26.2, and 26.3 — pick the one that matches your server.

Security note

Anyone who can open the bound address and port can execute console commands. Keep host: 127.0.0.1 unless you fully trust your network.
