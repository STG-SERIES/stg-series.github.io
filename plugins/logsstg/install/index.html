Install

Drop the jar in plugins/, restart, then open the URL printed in the console (default port 8765).

Download — CurseForge Source — GitHub

Setup in three steps

  1. Download the LogsSTG jar for your Paper version from CurseForge or GitHub Releases.
  2. Install into plugins/ and restart the server.
  3. Open http://127.0.0.1:8765/ (or the host/port in config.yml). Edit config, then /logsstg restart if needed.

First run creates

  • plugins/LogsSTG/config.yml
  • host · port · history
  • colors.background · colors.text
