Install

Grab the jar for your server line, drop it in plugins/, restart once, then tune configs.

Download — Modrinth Download — CurseForge Source — GitHub

Requirements

Server Java Notes
Paper or Purpur 1.21.11 21+ Use the 1.21.11 release on Modrinth / CurseForge
Paper 26.1 25+ Match jar to 26.1 — not interchangeable with other lines
Paper 26.1.2 25+ Dedicated build for 26.1.2
Paper 26.2 25+ Dedicated build for 26.2
Paper 26.3 25+ Dedicated build for 26.3

EcoSTG includes its own SQLite economy. You do not need Vault or another economy plugin.

Setup in three steps

  1. Download the EcoSTG jar that matches your Paper/Purpur version from Modrinth or CurseForge.
  2. Install by placing the jar in your server’s plugins/ folder. Start the server once.
  3. Configure — edit config.yml, worth.yml, and jobs.yml in the plugin data folder, then restart (preferred over /reload on Paper).

First run creates

  • config.yml
  • worth.yml
  • jobs.yml
  • ecostg.db

Existing configs keep your values when you update; new keys pick up defaults from the latest release.
