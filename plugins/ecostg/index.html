One plugin. Full server economy.

Lightweight economy, auction house, jobs, homes, friends, combat rules, and a pause-screen hub — built for Paper and Purpur. No Vault. SQLite under the hood.

Modrinth CurseForge GitHub See features

Why servers pick EcoSTG

Built-in economy

Balances, pay, shop, instant sell prices, and leaderboards — no extra economy plugin required.

Hub that players use

ESC pause button and /menu open the same dialog hub: homes, AH, TPA, RTP, settings, and more.

Jobs with teeth

Choose a job, sell on the AH with worker perks, and meet in-game deadlines — or face cooldowns.

Supported platforms

Download the jar that matches your server line from Modrinth or CurseForge.

  • Paper / Purpur 1.21.11 · Java 21+
  • Paper 26.1 · Java 25+
  • Paper 26.1.2 · Java 25+
  • Paper 26.2 · Java 25+
  • Paper 26.3 · Java 25+

Do not mix jars across server lines. Pick the build for your exact Paper version.
