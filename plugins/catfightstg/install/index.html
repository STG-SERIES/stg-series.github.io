Install

Paper 1.21.11, Java 21+, and the Paper plugin jar — not the Fabric/Forge mod.

Download — CurseForge Source — GitHub

Requirements

Server Java Notes
Paper 1.21.11 21+ Uses Paper mob goal API — Spigot not supported
Clients — Vanilla clients OK — no Fabric/Forge/NeoForge on players
Folia — Not supported

Setup in four steps

  1. Download the Paper plugin from CurseForge or GitHub Releases (e.g. catfighting-paper-1.21.11-*.jar).
  2. Clean up — remove any catfighting-fabric-*.jar, NeoForge, or Forge jars from plugins/ and plugins/.paper-remapped.
  3. Install the Paper jar in plugins/ and restart the server.
  4. Configure optional settings in plugins/CatFighting/config.yml, then /catfighting reload.
